Sample 01: Minimal Game

The smallest full game flow on the game management state machine: Main Menu, Play (a counter on scaled time), Pause (Esc or the HUD button), Game Over and Game Win (Retry reloads the scene, Quit returns to Main Menu), and one empty Settings menu opened from Main Menu and from Pause.

Open it

Open Scenes/Minimal Game.unity and press Play. Editor only; never in a build.

How it is set up

  • States/: one asset per state, the catalog (top wins: Game Win, Game Over, Settings, Pause, Play, Main Menu) and the settings. Pause's parent is Play; Settings' parents are Main Menu and Pause.
  • Game Management object: EnterOnSceneStart (Main Menu), InputToggleRequest (Pause key, only while Play is active), StateRequester for the buttons, and MinimalGameSceneFlow (starts the machine with these settings; Retry and Quit).
  • Each menu: a StateMenuReactor showing its panel. The HUD: HudToggleReactor. Settings: BackRequest (Back button, Backspace, gamepad East).

Test

MinimalGameFlowTests (PlayMode) presses every button in turn and records the top state, time scale, cursor and shown menus, then compares with Parity/baseline.json. Delete the baseline to record a new one.
