# Game management: agent context

Planning documents for making the game management module about 90% commercial-ready (ready for the Unity Asset Store).
Written in the planning session of 2026-11-25. Execution agents start here.

Note: Session 1 renames this module folder from `Modules/GameManagment` to `Modules/GameManagement`. Paths in these
documents use the new name unless they talk about the rename itself.

| File | What it holds |
|---|---|
| [PLAN-OVERVIEW.md](PLAN-OVERVIEW.md) | The grand plan: destination, sessions, budgets, rules every session follows. Read first. |
| [ANALYSIS.md](ANALYSIS.md) | How the module works today, its features, strengths and weaknesses, with evidence from the code. |
| [DESIGN.md](DESIGN.md) | The target design (from the codebase-design skill): the deep state machine, its seams, words, old-to-new mapping, cut list. |
| [DECISIONS.md](DECISIONS.md) | Every decision the user made in the planning grill, with their own changes. The source of truth when documents disagree. |
| [Wayfinder/map.md](Wayfinder/map.md) | The wayfinder map: destination, decisions so far, open tickets, fog, out of scope. |
| [DEFINITION-OF-DONE.md](DEFINITION-OF-DONE.md) | What "finished" means for a task and for a session. Every session prompt links it. |
| [Sessions/](Sessions/) | One folder per session: `OVERVIEW.md`, `PROMPT.md` and, when the session ends, `HANDOFF.html`. |
