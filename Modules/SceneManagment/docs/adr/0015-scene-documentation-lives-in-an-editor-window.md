# Scene documentation lives in an Editor window, not in HTML

The save system's documentation is static HTML that opens in a browser. The scene system's documentation is a UI Toolkit window inside the Unity Editor (Tools > External Project Tools > Scene System > Open Scene Documentation), with pages written as Markdown files in the module's Editor folder and the sample READMEs used as sample pages. Users stay in one application, and a page can act on the project: select or ping an object, open a Project Settings section, follow the sample scene that is open, and show what happens in Play. The browser bridge the HTML docs needed (a local ping server, custom URL protocols, `file://` redirect pages) goes away. The cost is our own Markdown renderer and window, and pages that read outside Unity only as plain Markdown on GitHub.

Unity's component header "?" (`HelpURLAttribute`) can only open an `http`, `https` or `file:///` URL, and Unity reads the URL when the header is first drawn, so it cannot open an Editor window safely. Help buttons are therefore drawn by the scene system's own windows, page sections and inspectors, all through one entry point, `SceneSystemDocs.Open(topicId)`.
