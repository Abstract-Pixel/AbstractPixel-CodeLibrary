# Sample scene groups never reach a build

The scene system puts every scene of a scene group into Build Settings, which would ship the library's samples inside a game. A scene group can be marked as a sample scene group: the scene system never writes its scenes to Build Settings, the Editor opens them in Play mode with `EditorSceneManager.LoadSceneAsyncInPlayMode`, the Scene System page lists them in their own section, and a build step stops any build that still contains one (Build Settings, a Build Profile or Addressables), naming the scene, with a fix button on the page. Stopping is chosen over silently removing them because a scripted build cannot change its scene list at that point, and the mistake should be seen. A scene used by a sample scene group and a game scene group is an error.
