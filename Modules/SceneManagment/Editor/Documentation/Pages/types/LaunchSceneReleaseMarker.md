# LaunchSceneReleaseMarker

Timeline marker for the launch scene's hand-off: the frame where the start scene group takes over. A LaunchSceneReleaseReceiver (or the launch scene's own director) releases the launch scene hold there.

**Kind:** class · **Namespace:** `AbstractPixel.SceneManagement.SceneScreens` · **File:** `LaunchSceneReleaseMarker.cs`
