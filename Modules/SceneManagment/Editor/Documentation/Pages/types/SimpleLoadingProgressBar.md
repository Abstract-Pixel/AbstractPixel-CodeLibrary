# SimpleLoadingProgressBar

The ready-made loading scene's plain progress bar: the fill's right edge follows the smoothed progress. It uses the RectTransform's anchors, so it needs no sprite and no art.

**Kind:** component · **Namespace:** `AbstractPixel.SceneManagement.SceneScreens` · **File:** `SimpleLoadingProgressBar.cs`
