# SceneSystemSettingsSource

Finds the scene system settings at runtime. A build loads them with Player Settings' Preloaded Assets before the first scene.

**Kind:** class · **Namespace:** `AbstractPixel.SceneManagement` · **File:** `SceneSystemSettingsSource.cs`

Read more in [Start up](../guide/start-up.md#pick-the-start-scene-group).

The Editor does not load Preloaded Assets for Play, so the scene system's editor code registers a lookup that finds the asset by type.
