# Scene documentation

<!-- layout new -->

The scene system opens, closes and switches groups of scenes: a main scene plus the manager scenes and shared scenes that come with it, with a screen effect, an optional loading scene, preload and relocation.

## Three ways in

- **[Get started](guide/get-started.md)**: set up the scene system and make your first scene change.
- **[Learn by playing](../../../Samples/README.md)**: ten samples, from a no-code button to a launch scene. Open one and this window follows it.
- **[Look something up](reference/find-a-problem.md)**: find a problem, the [code map](reference/code-map.md), the [types](types/SceneActions.md) and the [design decisions](reference/design-decisions.md).

## The parts

Start at the three core boxes; each opens its own map, and each part opens its guide page.

## Help everywhere

Every Scene System window, inspector and Project Settings section has a [help button](term:help-button) that opens this window at the part about it. The [glossary words](term:scene-group) show their meaning when you hover them.
