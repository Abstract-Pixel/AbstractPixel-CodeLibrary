What it does#

Put [Save] on a field and the save system captures it, writes it to a save file, and puts it back the next time that saved object exists. There is no Load call: a script gets its data when it registers, before its own Start runs.

Data lives in one of three save locations: shared by every game profile, inside one game profile, or inside one scene. See Choose where data goes.
