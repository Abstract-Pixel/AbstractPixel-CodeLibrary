Read or write a whole file 3 full control

SaveStorage reads or writes a whole save file as JSON text in one line. Game code should save through [Save] fields and SaveActions instead; this is for editor tools and debug buttons.

Sample 07 · Whole Files With SaveStorage

  1. Open the Whole Files With SaveStorage scene and press Play.
  2. Press Count a visit, then Save. The shown text includes the new visits count.
  3. Press Copy the file's text, count two more visits, then press Paste text into the file. The count goes back to the copied text.

Read, write, and find the file#

ReadText, WriteText, Delete and GetFilePath all take the same four shapes: nothing, a game profile, a scene, or both. A Scene file always needs its scene, as a SceneField picked in the inspector, so the save system never has to guess which one.

Works in edit mode too. An editor window can read and fix a save file without pressing Play. In play mode, WriteText and Delete also update the running game: the registered objects in that file restore from the new text, so you don't need to call Reload.
If it goes wrong
One error names the right call, and nothing happens
A wrong combination, such as a scene argument for a Global file. Match the save file's own save location.
Pasted text does nothing
The text isn't a whole, valid save file. WriteText logs an error and leaves the file untouched.
