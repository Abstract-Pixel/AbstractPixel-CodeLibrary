Get started

Create the config once, save a field, then pick up the ladder level you need.

Install 0 no code#

The save system is already part of this project, as a module of the Abstract Pixel Library. The one setup step is creating its config: see Set up a project.

The eight sample scenes ship with the module under Modules/SaveSystem/Samples/, next to its own Runtime/ and Editor/ folders. Their scripts sit in one Editor-only assembly, so a sample scene left in a build's scene list fails the build instead of shipping.

Your first saved value 1 daily code#

One script, one saved field, one check that it worked.

  1. Choose Tools > External Project Tools > Save System > Create Config.
  2. Add this script to any GameObject in a scene. The editor adds a Savable Bridge next to it.
  3. Press Play, press Take 10 damage twice, then Save.
  4. Stop, then press Play again.
Show the result"Health: 80" on the second Play. The field came back before Start, with no load call.

Next, read the ladder for what to learn after this, or play sample 01.

The ladder#

The save system has four levels. Most of a game only needs the first two. Each level builds on the one below it.

LevelWhoWhat you useSample
0No codeDesignersSaveTransform, SaveActiveState and SaveDestroyed components; MonoSaveActions on buttons; autosave in the config.02
1Daily codeDevelopers[Save] on a field. A plain class also calls SaveActions.Register(this). SaveActions.Forget(gameObject) for picked-up things.01, 08
2ChoicesDevelopersISaveIn<TFile> to pick the save file, IOnRestored, SetSaveId for spawned copies, save slots with SaveActions.GameProfiles.03, 04, 05
3Full controlTools, unusual casesISavable<TData> for data that isn't plain fields, SaveStorage for whole files.06, 07

Every how-to page carries its level, so you can skip what you don't need yet.
