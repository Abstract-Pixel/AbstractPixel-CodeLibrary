Forgetting saved data for good 1 daily code

A coin that was picked up should stay picked up. Destroy alone isn't enough.

Why a plain Destroy isn't enough#

Try it in the sample
Open sample 02: Buttons With No Code →

Sample 02 · Buttons With No Code

  1. Open the Buttons With No Code scene and press Play.
  2. Press Pick up the coin, then Save.
  3. Stop, then press Play again.

The coin is a GameObject placed in the scene. Every time the scene loads, Unity creates it fresh from the scene file, with its collider and its sprite intact. Plain Destroy only removes it from the running game. It leaves no trace the save system can find on the next load, so the coin comes back.

A coin that was picked up needs a note that says so. That note is the gone marker, written by Forget.

Forget it, then destroy it#

With a line of code, call SaveActions.Forget before Destroy. Forget needs the Savable Bridge still on the GameObject, so it has to run first.

With no code, add the SaveDestroyed component and call its DestroyAndForget from a UnityEvent, such as a button's On Click.

Always forget before you destroy. Destroy's own teardown unregisters the object first, so a separate, later Forget call can no longer find its entry.

What the save file keeps#

Forgetting a scene object doesn't remove its entry. It replaces it with a gone marker, so the save system remembers the object should stay off.

Show the result 
"9b1c44d0-.../a7e2f310-...": {
  "name": "Assets/Scenes/Level.unity/Coin (3)/Coin",
  "gone": true
}
Next time the scene loads, the coin's Savable Bridge reads the gone marker and turns the GameObject off before any other script's Start runs.

A plain class or a spawned copy works differently: Forget removes its entry outright, since nothing will create that object again on its own. A gone marker belongs to one game profile, so a new game has the coin again.

If it goes wrong
A picked-up coin comes back after a reload
Something called Destroy without Forget first. Use SaveActions.Forget(gameObject) or SaveDestroyed.DestroyAndForget.
Forget logs an error and changes nothing
No game profile is open. Forgetting GameProfile or Scene data needs one.
