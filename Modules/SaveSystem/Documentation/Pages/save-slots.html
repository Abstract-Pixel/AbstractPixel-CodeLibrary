Game profiles and save slots 2 choices

A game profile is one playthrough. You hold a GameProfile and call its methods; you never type its ID.

Try it in the sample
Open sample 03: Save Slots And Continue →

Sample 03 · Save Slots And Continue

  1. Open the Save Slots And Continue scene and press Play.
  2. Press Add 100 points, then Save.
  3. Press Create game profile, then Open on the new one. The points go back to 0.
  4. Press Back to the main menu, then Continue.

List the game profiles#

SaveActions.GameProfiles is never null. With no save system config it's an empty list, and its methods log one clear error instead of throwing.

Create a new one#

The new game profile gets the lowest free slot number and a name like "Game Profile 3". CreateNew doesn't open it; call Open() next if the player should start playing right away.

Open one#

Reload your scenes after opening another game profile. An object that stays alive across the switch keeps showing the old game profile's values until its scene reloads.

Continue: open the most recent#

LastOpened is null on a first launch, so a Continue button should hide or grey out when it is. SaveActions.GameProfiles.Count does the same for a Load button when there are no saves at all.

Rename a slot#

Renaming changes DisplayName only. The slot number stays the same, so nothing else about the game profile moves.

Delete a slot#

Delete removes the game profile's save files and backups. Deleting slot 2 leaves slot 3 as slot 3; the next new game profile still takes the lowest free number.

Show the resultEach save updates the open profile's last saved time, last scene and playtime. Put your own fields, such as difficulty, in profile.Custom; they're written on the next save and survive a list refresh.
If it goes wrong
Old values stay on screen after opening another game profile
The scene wasn't reloaded. Reload your scenes after Open().
No game profile opens at startup
The config's Startup Policy is Manual. Set it to AutoSetUp, or open one from your own main menu.

See also: designers can wire the same actions with no code through MonoSaveActions's Open Slot, New Game and On Game Profile Opened.
