SaveSystemConfigSO 0 no code

The one settings asset for the save system, at Assets/Resources/SaveSystemConfig.asset. It is the source of truth for folders, file type, the save file list and game profile names. Tools > External Project Tools > Save System > Create Config makes it.

Facts about the save system as a whole, not any one game profile — such as which game profile was opened most recently, so the game can reopen it at startup — are save system metadata. It's kept in Global, separately from this config asset.

Autosave is saving every save file without the game asking: on quit, on focus loss, when a scene unloads, or every few minutes — the four checkboxes above, all off by default.

The save file list itself is drawn below these fields: the built-in save files first, then the game save files and any a library module adds. Each row has a name, a save location, and a Backup checkbox — tick it to keep the previous good copy of that save file in the Backups folder, loaded instead if the file on disk is corrupt. If it goes wrong#

Show fixes
"Can't find the save system config" in the Console
Run Create Config. With no config, save calls do nothing and the game keeps running.
Two configs after a merge
Only the asset at Assets/Resources/SaveSystemConfig.asset is read. Delete the other one.
