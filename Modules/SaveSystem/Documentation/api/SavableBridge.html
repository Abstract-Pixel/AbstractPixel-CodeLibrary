SavableBridge 0 no code

Connects the saved scripts on this GameObject to the save system. A saved script implements ISavable<TData>, or puts [Save] on a field. The editor adds this component by itself, and it gives each saved script a save ID.

A save ID is the name a saved object's data is filed under in its save file. Only one live object can hold a given save ID in a given save file at a time. A plain class's save ID is its class name by default ("Inventory", then "Inventory 2" for a second live instance); a scene object's comes from its Savable Bridge; a spawned copy needs its own from SetSaveId, below.

(each saved script's card)—Shows that script's save ID and its saved fields, read from the save system's own view of it.

The editor adds this component by itself, the first time a script on the GameObject gets a [Save] field or implements ISavable.

In code#

A scene object never needs to call this directly. A spawned copy calls SetSaveId so it doesn't share its prefab's save ID.

Most scripts call SetSaveId through SavedScriptExtensions instead, directly on the saved script.
