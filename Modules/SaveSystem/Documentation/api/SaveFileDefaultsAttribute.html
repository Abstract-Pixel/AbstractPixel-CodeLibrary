SaveFileDefaultsAttribute 3 full control

Gives a library module's save file class its starting row in the config's save file list. The editor adds the row by itself; the owner can still change its save location and Backup box.

In code#

Use it only when no built-in save file fits, on a class that implements ISaveFile.

Properties

public string Nameproperty The row's name in the save file list.

If it goes wrong#

Show fixes
The row doesn't appear in the config
Open the save system config once in the Inspector; the editor adds missing default rows on validate.
The row keeps reappearing after the owner removes it
That's expected the first time. Removing a default row again after Update Save File Classes keeps it removed.

See also: ISaveFile, SaveLocation, Choose where data goes.
