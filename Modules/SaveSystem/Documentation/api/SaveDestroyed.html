In code#

Call DestroyAndForget, never Destroy directly. Forget must run first, while the Savable Bridge still has this object's entry. Destroy's own teardown unregisters it before a later, separate Forget call could find it.

Members#

Methods

public void DestroyAndForget()method Forgets this GameObject's saved data, then destroys it.
Equivalent to SaveActions.Forget(gameObject); Destroy(gameObject); in the right order. Forgetting a scene object writes a gone marker: a note, filed under this object's save ID, that it was removed during play. It belongs to one game profile like any other data, and makes the object turn itself off the next time its scene loads.
