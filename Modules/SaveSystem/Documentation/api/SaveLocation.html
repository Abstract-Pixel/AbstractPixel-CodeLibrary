SaveLocation 2 choices

One of the three places saved data can live: Global, Game Profile or Scene. There are never more than three, and developers can't add their own.

Members#

Values

Global = 1value Belongs to the player's machine, shared by every game profile.
Settings and input bindings live here. Global is only ever a save location, never the name of a save file.
GameProfile = 2value Belongs to one playthrough. The default save location.
See GameProfile for what one playthrough holds.
Scene = 3value Belongs to one scene within one game profile.
For data about one scene within one game profile, such as which chests in the Forest scene are open — always nested inside a game profile, never on its own. Not to be confused with a Unity scene asset, which is a different thing with the same name.

See also: Save locations, SaveFileDefaultsAttribute.
