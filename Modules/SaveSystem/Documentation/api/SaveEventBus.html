SaveEventBus 2 choices

Raises load events and save events. A load event fires when saved data is ready: one save file restored, or everything restored. Load events and OnGameProfileOpened are sticky: a script that subscribes after the event already happened is called right away. A Scene save file raises its load event once per scene, one frame after that scene's scripts start.

Members#

Events

public static event Action<Type> OnLoadCompletedevent One save file was read and every registered object in it restored. Sticky.
Gives the save file class. A Scene save file raises it once per scene.
public static event Action OnLoadAllCompletedevent Global data and the open game profile are restored. Sticky.
Raised each time a game profile opens.
public static event Action<GameProfile> OnGameProfileOpenedevent A game profile opened. Sticky.
Subscribing while one is already open calls the handler right away.
public static event Action OnSaveAllCompletedevent SaveAll finished writing every changed save file.
public static event Action<Type> OnSaveCompletedevent One save file was written.
Save<TFile>() raises it for that file. SaveAll raises it once per file it wrote.
public static event Action<Type, string> OnSaveFailedevent A save file could not be written.
Gives the save file class and a reason to show the player. The previous good save on disk is untouched.

Methods

public static void AddLoadListener<TFile>(Action handler)method Calls handler every time TFile's load event fires.
A typed load listener: a load event handler for one save file class. Sticky like every load event — subscribing after the file already loaded calls handler right away.
public static void RemoveLoadListener<TFile>(Action handler)method Stops handler from hearing about TFile's load event.

If it goes wrong#

Show fixes
A handler never runs
Check it subscribed to the right save file class with AddLoadListener<TFile>, not a different one.
An error names a handler and "threw"
That handler threw an exception. The save system logs it and keeps calling the other handlers; fix the one named in the message.
