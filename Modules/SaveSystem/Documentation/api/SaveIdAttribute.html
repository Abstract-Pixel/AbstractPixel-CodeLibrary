SaveIdAttribute 1 daily code

Keeps a class's automatic save ID the same after the class is renamed. Put it on a class registered with SaveActions.Register(object).

Attribute (class)

In code#

Without it, renaming the class changes its automatic save ID, and old saved data stops matching.

Add [SaveId("OldClassName")] using the class's name before the rename, so its save ID doesn't change.
