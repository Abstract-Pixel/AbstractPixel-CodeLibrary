In the Inspector#

Inspector labelAPI memberWhat it does
Chosen Save FileSaveChosenFile, ReloadChosenFileThe save file those two buttons and the four events below act on.
On LoadedOnLoadedThe chosen save file loaded, or was reloaded. Fires right away if it already happened.
On SavedOnSavedThe chosen save file was written successfully.
On Save FailedOnSaveFailedThe chosen save file could not be written. Carries a reason string to show the player.
On Game Profile OpenedOnGameProfileOpenedA game profile opened.

In code#

Usually wired entirely in the Inspector. A UI script can still read its events directly:

Members#

Properties

public UnityEvent OnGameProfileOpenedevent A game profile opened.
public UnityEvent OnLoadedevent The chosen save file loaded, or was reloaded. Sticky: fires right away if it already loaded.
public UnityEvent OnSavedevent The chosen save file was written successfully.
public SaveFailedEvent OnSaveFailedevent The chosen save file could not be written. Gives a reason to show the player.

Methods

public void NewGame()method Creates a new game profile in the lowest free slot and opens it.
public void OpenSlot(int slotNumber)method Opens the game profile in this slot. Does nothing, and logs a warning, if the slot is empty.
public void ReloadChosenFile()method Reloads the save file picked in the inspector, throwing away unsaved changes.
public void Save(SaveFileReference saveFile)method Saves one save file, passed in from code.
public void SaveAll()method Saves every save file that changed.
public void SaveChosenFile()method Saves the save file picked in the inspector.

If it goes wrong#

Show fixes
"was asked to SaveChosenFile, but no save file is picked"
Open the component's inspector and pick a save file under Chosen Save File.
On Loaded never fires
It's sticky but still only fires for the chosen save file. Check it's the one your game actually loads.
