In code#

Add the component in the Inspector. Nothing else to call.

Only an object that starts active can be turned off and restored. An object that starts inactive never runs its Awake, so it never registers with the save system at all.

Members#

Methods

public void OnRestored()method Sets this GameObject active or inactive to match the saved value.
Implements IOnRestored. Skips itself for one restore right after you turn the object back on at runtime, so it can't immediately turn itself off again.

If it goes wrong#

Show fixes
An object that starts inactive in the scene never saves
Expected: its Awake never runs, so it never registers. Start it active, or save its state from a parent object instead.
Turning the object on in code doesn't stick after a reload
Make sure you're turning it on through normal GameObject activation, not by disabling this component.
