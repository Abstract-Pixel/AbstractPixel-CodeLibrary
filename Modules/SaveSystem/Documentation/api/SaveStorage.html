SaveStorage 3 full control

Reads and writes whole save files as JSON text, for editor tools and debug buttons. The save system config says where each file lives and whether it keeps a backup.

In code#

Works in play mode and in edit mode. In play mode, WriteText and Delete also update the running save system: registered objects in that file are restored from the new text.

Members#

Properties

public static IReadOnlyList<GameProfile> GameProfilesproperty Every game profile, sorted by slot number.
In edit mode they're read from disk.

Methods

public static bool ReadText<TFile>(out string json)method Reads a Global file, or the open game profile's GameProfile file.
Overloads take a GameProfile, a SceneField, or both, for a file that isn't the open profile's.
public static bool WriteText<TFile>(string json)method Writes a Global file, or the open game profile's GameProfile file. Atomic.
Same overloads as ReadText.
public static bool Delete<TFile>()method Deletes a save file and its backup.
Same overloads as ReadText.
public static string GetFilePath<TFile>()method The full path of a save file, for "Show in Explorer".
Same overloads as ReadText.

If it goes wrong#

Show fixes
ReadText returns false
The file doesn't exist yet, or there's no save system config. Check SaveSystemToolsMenu's Open Debug Folder to see what's on disk.
A Scene file call throws or returns false with no scene given
A Scene save file always needs its scene, as a SceneField argument.
