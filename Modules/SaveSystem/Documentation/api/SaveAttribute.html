SaveAttribute 1 daily code

Marks a field to save and restore automatically, keyed by its name, with no other code. Works on a MonoBehaviour, a ScriptableObject, or a plain class registered with SaveActions.Register.

Members#

Properties

public string Formerly { get; set; }property The field's old name. Read when the new name is missing from a save file.
The former field name is the name a saved field had before it was renamed. Set Formerly to it once, right after the rename, and leave it: saved data under the old name still loads, so the rename never loses it.

If it goes wrong#

A blocking mistake is one the editor can see at a glance, such as [Save] on a GameObject field, or on a class that also implements ISavable. It logs one error naming the fix, stops play mode from starting, and fails the build.

Show fixes
"[Save] on a GameObject field" error, play mode won't start
The save system can't serialize a GameObject or Component reference. Save an ID or index instead.
A renamed field reset to its new-game value
Add Formerly with the field's old name so older saves still load into it.
