SaveFiles 1 daily code

The five built-in save files every game has: GameProfile and Scene, which live in their own save locations, and Settings, Input and Achievements, which live in Global. Library modules and game code both use them, such as SaveActions.Save<SaveFiles.Settings>(). Only GameProfile's name and save location are locked; every other built-in file can be renamed, moved and backed up like any row in the save file list.

In code#

A game save file is one the game adds to the save file list, such as Ghosts. The game's own save files live in GameSaveFiles, a class the editor writes from the config's save file list.

Members#

Nested types

public sealed class GameProfile : ISaveFiletype Data about one playthrough, such as health and inventory.
Saved objects with no save file choice use it. Lives in the game profile's own save location.
public sealed class Scene : ISaveFiletype Data about one scene within one game profile.
Such as which chests in the Forest scene are open.
public sealed class Settings : ISaveFiletype The player's settings.
Lives in Global, so every game profile shares it.
public sealed class Input : ISaveFiletype The player's input bindings.
Lives in Global.
public sealed class Achievements : ISaveFiletype The player's achievements.
Lives in Global.

If it goes wrong#

Show fixes
Data saved to SaveFiles.Scene doesn't show up for another scene
That's expected. Each scene gets its own Scene save file within a game profile.
