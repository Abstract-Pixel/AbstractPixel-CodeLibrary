ISaveIn<TFile> 2 choices

Picks the save file a class's data goes in, for a class whose saved data is its [Save] fields. With neither this nor ISavable<TData, TFile>, the data goes in SaveFiles.GameProfile.

Members#

ISaveIn<TFile> has no members. Writing : ISaveIn<SaveFiles.Scene>, as Chest does above, is the whole API: the save system reads which file class fills in TFile. There's no method to call.

If it goes wrong#
