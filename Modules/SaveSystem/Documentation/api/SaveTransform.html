SaveTransform 0 no code

Saves this GameObject's position, rotation and local scale, with no other code.

A ready-made saver is a component that saves one common thing about a GameObject with no code: Save Transform, Save Active State or Save Destroyed.

In code#

Add the component in the Inspector. Nothing else to call: it saves on every save and restores itself through IOnRestored.

A scene object usually gets it from the Inspector instead. A spawned copy, like the enemy above, still needs its own save ID: see Save plain classes, ScriptableObjects and spawned copies.

Members#

Methods

public void OnRestored()method Copies the saved position, rotation and local scale back onto this GameObject's Transform.
Implements IOnRestored. Runs right after a restore, including when new-game values apply.

If it goes wrong#

Show fixes
The GameObject snaps to its old position for one frame, then moves
Something else sets transform.position in Start, after OnRestored already set it. Move that code to read the Transform instead of a hardcoded value.
A spawned copy doesn't restore
Give it a save ID with SetSaveId right after Instantiate. See Save plain classes, ScriptableObjects and spawned copies.

See also: SaveActiveState, SaveDestroyed, React after a restore: IOnRestored.
