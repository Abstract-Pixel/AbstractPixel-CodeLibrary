ISaveFile 2 choices

Marks a save file class, such as SaveFiles.Settings or GameSaveFiles.Ghosts. You write the class wherever you mean that save file, so a typo doesn't compile.

A save file is a named file of saved data that lives in exactly one save location. Every game has the built-in save files; designers add game save files of their own.

In code#

The built-in save files ship with the library in SaveFiles. Game save files come from GameSaveFiles.cs, which the editor writes from the config's save file list. A library module ships its own class with SaveFileDefaultsAttribute.

Members#

No members. ISaveFile is a marker interface: a save file class implements it with an empty body, and its type is the only thing the save system reads.

If it goes wrong#

Show fixes
"No such save file" at runtime
The class implements ISaveFile but isn't in the config's save file list. Add a row for it.
