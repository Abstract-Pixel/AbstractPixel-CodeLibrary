GameProfile 2 choices

One game profile, such as "Game Profile 1": one playthrough of the game, and the save location for data about that playthrough, such as the player's health and inventory. Hold it, show it on a save slot screen, and call Open() or Delete() on it. You never type its ID.

In code#

A GameProfileList (from SaveActions.GameProfiles) hands out every GameProfile instance. You never construct one yourself.

Members#

The properties below are the game profile manifest: the summary a save slot screen shows for one game profile, such as its name, slot number, last saved time, playtime and last scene.

Properties

public Dictionary<string, string> Customproperty Your own fields for the save slot screen, such as difficulty or chapter.
Written on the next save. Read and write it like any dictionary.
public string DisplayNameproperty The name players see, such as "Game Profile 1" or a custom name.
"Game Profile" plus its slot number is the default game profile name, set by the config. Call Rename to give it a custom name instead.
public bool IsOpenproperty True while this is the open game profile.
public string LastSceneproperty The scene that was active at the last save.
public DateTime? LastSavedproperty When this game profile was last saved, in local time, or null if it was never saved.
public TimeSpan Playtimeproperty How long this game profile has been played, counted up to its last save.
public int SlotNumberproperty The number the save slot screen shows. It never changes.
Deleting slot 2 leaves slot 3 as slot 3 — slot numbers never shift. The next new game profile takes the lowest free number.

Methods

public void Delete()method Deletes this game profile and all of its save files.
If it was open, no game profile is open afterwards.
public void Open()method Opens this game profile: its saved objects are restored and its data is saved from now on.
public void Rename(string newDisplayName)method Changes the name players see. The slot number stays the same.

If it goes wrong#

Show fixes
Open() seems to do nothing
Check there's a save system config (Tools > External Project Tools > Save System > Create Config). Without one, SaveActions.GameProfiles is always empty.
Delete() removes slot 2, and slot 3 becomes slot 2
It doesn't. Slot numbers never shift; the next new game profile takes the lowest free number instead.
