SavedScriptExtensions 2 choices

Lets any saved script on a spawned copy's GameObject give it its own save ID, without finding the Savable Bridge first.

A spawned copy is a saved object created from a prefab while the game runs. It needs its own save ID because every copy of a prefab starts with the same one.

In code#

Call it right after Instantiate, before the copy's Start. Every copy of a prefab starts with the same save ID, so each one needs its own before it registers.

If it goes wrong#

Show fixes
"SetSaveId... needs a Savable Bridge on the same GameObject"
The GameObject has no saved script with a [Save] field yet, so the editor hasn't added a Savable Bridge. Add one manually, or add a [Save] field first.
