Properties

public IReadOnlyList<GameProfile> Allproperty Every game profile, sorted by slot number.
public int Countproperty How many game profiles exist.
For a save slot screen that only needs the count.
public GameProfile Currentproperty The open game profile, or null when none is open.
public GameProfile LastOpenedproperty The game profile that was open the last time the game quit, or null for a first launch or if it was deleted since.
For a Continue button. A New Game button uses CreateNew instead.

Methods

public void CloseCurrent()method Closes the open game profile, for example when the player goes back to the main menu.
public GameProfile CreateNew()method Creates a game profile named with the default game profile name and slot number, in the lowest free slot. It doesn't open it.
An overload takes a custom displayName instead.
public GameProfile Get(int slotNumber)method The game profile in this slot, or null if the slot is empty.

If it goes wrong#

Show fixes
All is always empty
There's no save system config yet. Run Tools > External Project Tools > Save System > Create Config.
CreateNew reuses a slot you just deleted
That's by design: deleting a slot frees its number, and the next CreateNew takes the lowest free one.
