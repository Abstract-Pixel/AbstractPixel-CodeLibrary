FileExtension 2 choices

The file type of save files on disk. The save system writes JSON either way, so json and txt are the real choices.

In code#

Picked per save file row in the SaveSystemConfigSO inspector, not usually read in code.

Members#

Values

jsonvalue The default. A save file written as formatted JSON.
Use this unless you have a reason to read the file as plain text elsewhere.
txtvalue The same JSON content, with a .txt extension.
Useful when a platform or a support tool expects a .txt file.

The other values (None, xml, bak, tmp) are marked [Obsolete]. The save system only ever writes JSON; picking one of them only changes the file's extension and logs a warning.
