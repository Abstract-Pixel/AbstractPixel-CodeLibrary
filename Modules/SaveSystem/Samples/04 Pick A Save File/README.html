04 Pick A Save File 2 choices

Each saved script picks its save file with ISaveIn<TFile>. The volume goes in the Global Settings file every game profile shares, the coins in the GameProfile file, and the chests in the Scene file, across two scenes.

Scene
Pick A Save File Forest, Pick A Save File Cave
Scripts
Chest.cs, PlayerCoins.cs, VolumeSetting.cs, PickASaveFileScreen.cs
Save file
Built-in Settings (Global), GameProfile and Scene (nothing to add to the config)
Guide
Choose where data goes

Try it

  1. opens the scene in Unity, then press Play.
  2. Press Volume up, Add 5 coins and Open Chest 1, then Save everything.
  3. Press Go to Pick A Save File Cave, then go back. Chest 1 is still open: each scene keeps its own chests.
  4. Press Add 5 coins and Volume up, then Save only the settings, then Undo unsaved coins. The coins go back; the volume stays.
  5. Press New game profile. The volume stays, the coins go back to 0, and the chests are closed.
  6. Press Next game profile to go back. The coins and the open chest return.
You should seeGlobal data survives a new game profile. GameProfile and Scene data don't.

The lines that matter

The config decides where each save file lives. A script only names the file's class. Use a built-in class (SaveFiles.GameProfile, Scene, Settings, Input, Achievements) or one of your own rows from GameSaveFiles.

Reload the scene after opening another game profile. Objects from the old profile never write into the new one.
