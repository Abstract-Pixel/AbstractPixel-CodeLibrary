08 ScriptableObject 1 daily code

A GameProgress asset with [Save] fields that registers itself in OnEnable. A later step of the save system makes the registering automatic.

Scene
ScriptableObject
Scripts
GameProgress.cs, GameProgressScreen.cs
Asset
Game Progress.asset
Save file
Built-in GameProfile (nothing to add to the config)
Guide
Save plain classes, ScriptableObjects and spawned copies

Try it

  1. opens the scene in Unity, then press Play.
  2. Press Complete a level and Earn a star, then Save.
  3. Stop, then press Play again.
You should seeThe levels and stars come back.

The lines that matter

In the Editor, Unity can load the asset before play mode starts the save system, so OnEnable runs too early. GameProgressScreen.Awake registers the asset again to cover that. Registering twice is harmless.

Values you change on an asset in play mode stay in the Editor's memory after you stop, until the save system restores the saved ones on the next Play.
