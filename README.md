# Abstract Pixel Code Library

A framework for Unity projects: core utilities, architectural foundations and feature modules. Much of it was moved over and refactored from past Abstract Pixel Studios projects.

Needs Unity 6.6 or newer.

## Installation

### From a local disk
1. Open the **Package Manager** in Unity.
2. Click the `+` icon and choose **Add package from disk...**.
3. Select the `package.json` file in your local copy.

### From a git URL
1. Open the **Package Manager**.
2. Click the `+` icon and choose **Add package from git URL...**.
3. Paste `https://github.com/Abstract-Pixel/AbstractPixel-CodeLibrary.git`
